# Inspiration and credits

This project is a Star Wars-themed Herdr layout. Its design direction was informed by the Herdr Middle-earth project supplied as a reference:

- [joaovitorwoliveira/herdr-middle-earth](https://github.com/joaovitorwoliveira/herdr-middle-earth)

That project is an inspiration and an important reference for how a themed Herdr workspace can bring its layout, agent presentation, and artwork together. The Star Wars naming and presentation in this repository are maintained separately; the earlier `Fellowship` labels have been removed rather than carried into the Star Wars identity.

## What is inherited and what is customized

This repository is an adaptation, not a claim that every part was written from scratch. The `cloned_from` fields in the mod metadata record Herdr mod lineages: `agents`, `toast`, `workspace-status`, and `spaces` version `0.1.16`. Those metadata records are retained to make the upstream lineage explicit.

Star Wars-specific work in this repository includes the paired Light Side/Dark Side palettes, the ship and character artwork, generated cockpit backgrounds, character assignment, miniature battles, and the standalone arena scene. The artwork generators in `tools/` make those assets reproducible from the source files in this project.

The pixel-art treatment also takes visual inspiration from [Darth Vader CSS Pixelart](https://github.com/alexaquino/darth-vader-css-pixelart).
